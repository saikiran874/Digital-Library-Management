# 📚 Digital Library Management System

A web-based Digital Library Management System developed using HTML, CSS, JavaScript, Python Flask, and MySQL.

The system allows users to browse books, search for books, borrow and return books, track borrowed books, and manage their account. Administrators can manage the library book collection through a dedicated admin panel.

---

## ✨ Features

### 👤 User Features

- User Registration
- User Login and Logout
- Browse Available Books
- Search Books
- Filter Books by Category
- View Book Details
- Read Digital Books
- Borrow Books
- Return Books
- View My Borrowed Books
- Reading Progress
- User Dashboard

### 🛠️ Admin Features

- Secure Admin Login
- Admin Dashboard
- View All Books
- Add New Books
- Edit Book Information
- Delete Books
- View Book Availability
- Admin Access Protection
